# Brew & Crumb

A mobile-first café preorder prototype built around the complete customer journey: browsing, choosing an item, managing a basket, selecting fulfilment, checking out, and reviewing an account.

![Brew & Crumb mobile app](https://github.com/user-attachments/assets/db3e1e0f-4662-4291-abf3-8086e3477c40)

## Experience covered

- Branded splash and home screens
- Menu browsing by category
- Item detail and option selection
- Basket review and editing
- Delivery or collection flow
- Prototype checkout and confirmation
- Account and order information

## Technology

React, TypeScript, Vite, React Router, Material UI, Radix UI primitives, Tailwind CSS, and Motion.

## Run locally

```bash
git clone https://github.com/elenichas/Brewandcrumbapp.git
cd Brewandcrumbapp
npm install
npm run dev
```

Use `npm run build` to create a production build.

## Project scope

This repository is a front-end product prototype. Review and replace sample content, pricing, fulfilment logic, and checkout behaviour before connecting it to a production service.
